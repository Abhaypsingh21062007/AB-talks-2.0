# ABTalks — 60-Day Build Challenge

> **Build every day. Show your work. Become undeniable.**

A mobile-first redesign of **ABTalks**, a 60-day coding challenge platform designed for Indian college students.

ABTalks helps students build consistency by challenging them to build something every day and publicly document their progress through:

- GitHub commits/repositories
- LinkedIn posts

The goal is to turn daily learning into visible proof of work.

---

## 🚀 Project Overview

ABTalks runs a **60-day coding challenge** where students:

1. Choose a coding track.
2. Build something every day.
3. Submit GitHub proof of work.
4. Share their progress on LinkedIn.
5. Maintain a public learning streak.
6. Build a visible portfolio over 60 days.

The existing product works, but this project focuses on **reimagining the experience through thoughtful UI/UX and a mobile-first design**.

The primary target audience is college students who often use the platform on their phones, especially late at night after college.

Therefore, the entire experience has been designed with **390px mobile screens as the primary viewport**.

---

# 🎯 Challenge Objective

The objective of this redesign is to create a platform that feels:

- Modern
- Premium
- Student-focused
- Technical
- Motivating
- Trustworthy
- Easy to understand
- Fast to use
- Mobile-first

The design focuses on making the student's daily journey extremely clear:

> **Open ABTalks → See today's goal → Build → Submit proof → Keep the streak alive.**
